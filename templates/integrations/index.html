Pre-Publication Stage-Gate Workflow
Add to .github/workflows/brandguard-gate.yml in your repository 
name: BrandGuard Pre-Publication Compliance Gate

on:
  pull_request:
    paths:
      - 'copy/**'
      - 'content/**'
      - 'site/marketing/**'

jobs:
  brand-governance-audit:
    name: Audit Marketing Copy & Legal Compliance
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: BrandGuard AI Stage-Gate Check
        id: brandguard
        run: |
          # Read proposed marketing copy changes
          CONTENT=$(cat copy/announcement.txt | tr -d '\n')
          
          # Query BrandGuard CI/CD Quality Gate Endpoint
          RESPONSE=$(curl -s -X POST https://brandgovernanceai.onrender.com/api/v1/gate/check \
            -H "Content-Type: application/json" \
            -d "{\"text\": \"$CONTENT\", \"threshold\": 85, \"jurisdiction\": \"GLOBAL\"}")
          
          echo "Response: $RESPONSE"
          
          # Parse gate pass/fail
          PASSED=$(echo $RESPONSE | jq -r '.passed')
          SCORE=$(echo $RESPONSE | jq -r '.overall_score')
          
          if [ "$PASSED" != "true" ]; then
            echo "::error::BrandGuard Quality Gate Failed! Compliance Score: $SCORE/100 (Threshold: 85)."
            exit 1
          fi
          
          echo "BrandGuard Quality Gate Passed with Score: $SCORE/100"
Guaranteed Zero Drift: If a pull request contains unverified claims like #1 in the world or fails WCAG contrast, the workflow automatically exits with code 1, preventing the pull request from being merged.

Python (requests) 
import requests

url = "https://brandgovernanceai.onrender.com/api/v1/gate/check"
payload = {
    "text": "Accelerate brand governance with audited, SLA-backed compliance.",
    "threshold": 85,
    "jurisdiction": "GLOBAL"
}

resp = requests.post(url, json=payload, timeout=10)
data = resp.json()

if data.get("passed"):
    print(f"Gate Passed! Score: {data['overall_score']}/100")
else:
    print(f"Gate Failed! Violations: {len(data['critical_violations'])}")
